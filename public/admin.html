Settings

Saving a changed setting validates the whole configuration, then restarts the server so it takes effect. Secrets are never shown or exported; leave a secret blank to keep it. Clearing any other field unsets it.

CIMD client documents

Served publicly at /cimd/<name>.json. The client_id is always set to the document's own URL. Changes apply immediately. Deleting a built-in document restores its default. For a client to be accepted, its URL must also match OAUTH_CIMD_CLIENT_ID_PATTERNS, and your authorization server must allow it.
