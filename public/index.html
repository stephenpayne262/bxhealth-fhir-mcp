    Connect your assistant

    First configure AIC to allow this site's CIMD URLs and the MCP audience above. Login callbacks run on your computer, not in Kubernetes. AIC must be able to fetch the CIMD documents over public HTTPS; localhost URLs are for previewing this page only. Leave client secrets blank for these public clients. Never paste access tokens into chat.

    Claude Code

    Register the HTTP server, then run /mcp in Claude Code and authenticate. Remove an existing entry with the same name before replacing it.

    claude mcp add --transport http \
  --client-id {{ORIGIN}}/cimd/claude-code.json \
  --callback-port 8765 \
  bxhealth-fhir {{PUBLIC_URL}}
    Claude Code client metadata

    Gemini CLI

    Merge this entry into your Gemini settings (for example ~/.gemini/settings.json), preserving other servers. Then run /mcp auth bxhealth-fhir in Gemini.

    {
  "mcpServers": {
    "bxhealth-fhir": {
      "httpUrl": "{{PUBLIC_URL}}",
      "oauth": {
        "enabled": true,
        "clientId": "{{ORIGIN}}/cimd/gemini-cli.json",
        "redirectUri": "http://localhost:7777/oauth/callback",
        "scopes": ["fhir-mcp:read"]
      }
    }
  }
}
    Gemini CLI client metadata

    MCP Inspector

    npx @modelcontextprotocol/inspector
    1. Select Streamable HTTP and URL {{PUBLIC_URL}}.
    2. Set OAuth client ID to {{ORIGIN}}/cimd/mcp-inspector.json, request scope fhir-mcp:read, and connect/authenticate.
    3. Keep the callback on port 6274. If using direct browser mode, configure the server's allowed origins for your Inspector origin.

    Run Inspector only in your approved development environment; this command is not a Kubernetes deployment command.

    MCP Inspector client metadata

    VS Code

    code --add-mcp '{"name":"bxhealth-fhir","type":"http","url":"{{PUBLIC_URL}}","oauth":{"clientId":"{{ORIGIN}}/cimd/vscode.json"}}'

    Run MCP: List Servers, select bxhealth-fhir, and authenticate. AIC does not currently advertise CIMD support. If VS Code attempts DCR and offers Copy URIs & Proceed, enter the client metadata URL above manually and leave the secret blank.

    VS Code compatibility needs validation: the current document's portless loopback URI does not guarantee AIC accepts VS Code's actual callback port/path. Check the callback against the document and AIC profile. AIC must also allow VS Code's origin for discovery CORS and the callback in its CSP.
